# [![src/tools/: The 44 MCP tool implementation modules](../../.github/assets/banners/src-tools.svg)](https://github.com/ganjoor)

The 44 MCP tools implemented across 7 domain modules.

## Tool Modules

- `registry.ts` — `defineTool()` helper ensuring uniform error handling, Zod validation, and dual markdown/JSON output formatting.
- `poets.ts` — Poet discovery, biographies, century groupings, and book listings.
- `categories.ts` — Category navigation, sub-category browsing, geotags, and people graphs.
- `poems.ts` — Full-text search, semantic search, poem details, verses, random poems, and Hafez divination (`faal`).
- `analysis.ts` — Prosody/rhythm detection, rhyme analysis, similar poems, and structural sections.
- `audio.ts` — Recitation search, audio details, and per-verse synchronization timing.
- `people.ts` — Related-people graph, family trees, comments, and editorial FAQ items.
- `content.ts` — Manuscript images, quotations, corrections, and geotags.
